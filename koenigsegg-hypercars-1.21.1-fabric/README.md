## GitHub & Gradle Build
1. Extract this archive and upload or push it directly to GitHub (under 100 files total, with `.gitignore`, `.gitattributes`, and `.github/workflows/build.yml` preconfigured).
2. GitHub Actions automatically builds the mod on JDK 21 and attaches the compiled `.jar` artifact.
3. Or build locally with `gradle build` (JDK 21) and copy the JAR from `build/libs/` into `mods/` alongside Fabric Loader, Fabric API, and GeckoLib (Fabric).

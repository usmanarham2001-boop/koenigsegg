# Koenigsegg Cars 2.0 (Fabric, Minecraft 1.21.1)

Four fully customizable, drivable hypercars with engine sound and horn:
Jesko (white / lime), Regera (red), Gemera (grey / yellow interior, 4 seats), CC850 (silver / red).

## Build the jar
- Windows/Mac/Linux: install JDK 21 + Gradle 8.8, run `build.bat` (or `./build.sh`).
- No tools: upload this folder to a GitHub repo, Actions > "Build mod jar", download the artifact.
Output: `build/libs/koenigsegg-cars-2.0.0.jar`.
Install with Fabric Loader 0.16.5+ and Fabric API 0.102.0+1.21.1 in `.minecraft/mods`.

## Controls
- Spawn eggs: Creative > Spawn Eggs tab. Right-click a car to get in (doors lift when it is empty).
- W / S throttle and reverse, mouse steers, Shift exits.
- **G** - open the paint shop (while driving, or while looking at a car).
- **H** - horn.  (Both keys can be rebound in Controls > "Koenigsegg Cars".)

## Customization (G)
Hex color for: body, accents, aero/carbon, glass, headlights, rims, seats, steering wheel, dashboard
(">" cycles 20 preset colors). Options: spoiler (none / lip / big wing / GT wing),
wheel style (disc / spoked / disc + cap), stripes (none / center / dual / triple).
Settings are saved with the car and shared with every player on a server.

## Sounds
`engine_loop.ogg` (pitch and volume follow speed and throttle) and `horn.ogg` are generated by
`tools/make_assets.py` - swap in your own OGG files with the same names to change them.
Textures (paint, carbon, leather, plain) are in `assets/cars/textures/entity/`; they are tinted
by the chosen colors, so keep them light/grey.
